# 6. Top-Right Profile Avatar & Consolidated Settings Sheet

**Context & Decision**: 
To shrink HeaderCommandDeck height and eliminate visual clutter, system management features (Theme mode, Language switcher, Backup & Restore, Level details) are consolidated into a modal Settings & Profile Sheet opened via a Top-Right Profile Avatar.

**Consequences**: 
- Significantly reduces Header vertical footprint to a compact bar (~56-64px).
- Centralizes app settings in one predictable entry point without adding bottom tabs.
