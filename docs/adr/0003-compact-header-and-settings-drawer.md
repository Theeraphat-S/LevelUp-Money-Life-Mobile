# 3. Compact Context-Aware Header & Settings Consolidation

**Context & Decision**: 
The initial HeaderCommandDeck consumed ~108px of vertical height across all tabs with overloaded utility buttons (Theme, Language, Data Backup, Badges). We decided to consolidate infrequent system controls into a unified Settings/Profile drawer or sheet, converting the top header into a slim, context-aware bar focused strictly on Month Filtering and essential page context.

**Consequences**: 
- Reclaims substantial vertical viewport real estate for Bento cards and financial content.
- Improves visual hierarchy by eliminating competing action buttons from primary screens.
- Moves language/theme/backup controls to a dedicated secondary navigation screen/sheet.
