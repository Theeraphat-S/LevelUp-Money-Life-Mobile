# 4. All-in-One Smart Numpad & Quick Template Layout

**Context & Decision**: 
To minimize transaction logging time to under 3 seconds, we chose an All-in-One Single View for QuickAddSheet containing a top numeric display with horizontal Quick Template chips, a middle Category selection strip, and an ergonomic bottom Smart Numpad.

**Consequences**: 
- Eliminates tab switching and keyboard pop-up delays.
- Ensures all essential controls are within single-thumb reach.
