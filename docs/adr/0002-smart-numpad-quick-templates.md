# 2. Smart Numpad & Quick Template Input System

**Context & Decision**: 
Standard mobile keyboards create excessive friction when entering amounts and navigating between form fields. We decided to implement an in-app Smart Numpad with embedded math calculation and 1-tap category selection, supplemented by Quick Frequent Templates (e.g., Daily Coffee, Meal) for 1-tap instant logging.

**Consequences**: 
- Replaces standard system virtual keyboard in QuickAddSheet with a dedicated numeric layout.
- Enables 1-tap fast logging under 3 seconds.
- Requires local storage or frequency analysis to populate quick template suggestions.
